# 🌐 Advanced Responsive Portfolio Website

A modern, fully responsive, and accessible personal portfolio website built using **HTML5, CSS3, and JavaScript**.  
This project is designed for internship submission and demonstrates advanced frontend development skills including responsive layouts, theme switching, and multi-page architecture.

---


## 📁 Project Structure

---

## 🎯 Features

- ⚡ Fully responsive mobile-first design
- 🎨 Advanced CSS3 styling (Grid + Flexbox)
- 🌙 Light / Dark mode theme toggle
- 🔐 Simple login & logout UI flow
- 📄 Multi-page architecture (Home, About, Projects, Contact)
- ♿ Accessibility support (ARIA labels, semantic HTML5)
- 🔍 SEO-friendly meta tags
- 🎯 Clean and modern UI/UX design
- 📱 Cross-browser compatibility

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, Variables)
- JavaScript (Vanilla JS)
- Git & GitHub Pages
